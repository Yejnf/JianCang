# 剪藏

`剪藏` 是一个轻量级 Windows 剪贴板历史器。它常驻后台托盘，自动记录运行期间产生的文字、图片和图文剪贴板内容，并提供托盘快捷菜单、全局快捷键、搜索、固定、去重、自动清理和开机自启等能力。

> 应用名：剪藏  
> 本地构建产物：`dist\剪藏.exe`  
> 发布下载：请在本仓库的 GitHub Releases 页面下载最新版 EXE  
> 数据目录：`%AppData%\JianCang`

## 获取方式

### 普通用户

请前往本仓库的 GitHub Releases 页面下载最新版 `剪藏.exe`。下载后双击运行即可，无需安装。

源码仓库主要保存代码、构建脚本和文档；正式发布的 EXE 建议作为 Release 附件提供，不直接提交到仓库中。

### 开发者

如果你想从源码构建，请克隆仓库后在项目根目录运行构建脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

构建成功后会在本地生成：

```text
dist\剪藏.exe
Assets\剪藏.ico
```

## 功能特性

- 后台监听剪贴板，记录文字、图片以及同时包含文字和图片的记录。
- 托盘右键显示最近 20 条复制记录，点击任意记录可直接复制回剪贴板。
- `Ctrl + Shift + V` 全局快捷键呼出快捷历史菜单。
- 完整历史窗口支持按内容、类型、来源、窗口标题、时间搜索。
- 支持单选、多选、全选、清空所选、清空全部。
- 所有清空操作都会弹出二次确认。
- 支持固定常用记录，固定记录优先显示，且不会被自动清理删除。
- 默认开启去重，相同内容不会反复堆积。
- 支持自动清理规则：按保留条数或保留天数清理非固定记录。
- 支持开机自启设置。
- 记录复制来源程序，方便按来源检索。
- 支持纯文本复制，图文记录也可以只复制文字部分。
- 单实例运行，重复打开会唤醒已有实例。
- 关闭历史窗口后继续托盘后台监听。

## 快速开始

从 GitHub Releases 下载 `剪藏.exe`，或在本地构建生成 `dist\剪藏.exe` 后双击运行。

启动后默认不会弹出主窗口，会挂到系统托盘后台运行。可以通过以下方式使用：

- 右键托盘图标，查看最近 20 条复制记录。
- 点击托盘菜单里的“查看历史记录”，打开完整历史窗口。
- 使用 `Ctrl + Shift + V` 呼出快捷历史菜单，点击记录可复制，点击菜单外区域会关闭菜单。
- 双击托盘图标打开完整历史窗口。

如果托盘图标没有直接显示，请在任务栏右下角的隐藏图标区域中查找。

## 使用说明

### 托盘菜单

右键托盘图标后可使用：

- `查看历史记录`：打开完整历史窗口。
- `最近20条复制记录`：点击某条记录可直接复制回剪贴板。
- `清空全部记录`：二次确认后清空全部历史。
- `设置`：配置去重、开机自启、全局快捷键和自动清理规则。
- `退出`：退出后台程序。

### 历史窗口 (全新 2.0 现代商业级界面)

历史窗口采用现代 Windows 11 Fluent 风格卡片流与双栏沉浸式设计：

- **一体化搜索胶囊**：位于顶栏中央，支持快捷键 `Ctrl + F` 快速聚焦搜索，实时匹配文本、图片、来源程序与窗口标题，支持一键清空与 `Esc` 恢复。
- **分类胶囊选项卡**：支持 `全部`、`★ 已固定`、`📝 纯文字`、`🖼️ 图片` 一键快速分类切换，实时显示对应分类的记录计数徽章。
- **现代自绘双缓冲卡片流**：
  - 核心内容前置排版，支持多行自适应预览与智能链接/代码胶囊识别。
  - 图片类型卡片内嵌高清圆角缩略图，告别枯燥的纯文字表格。
  - 来源程序胶囊与相对时间标签（如“刚刚”、“3分钟前”、“10:24”、“昨天”）。
  - **悬停快捷动作条**：鼠标移动到任意卡片上时，卡片右上角淡入显示快捷动作按钮：
    - `📋` 一键复制回剪贴板并提示气泡。
    - `★` / `☆` 一键切换置顶状态。
    - `🗑` 一键删除此记录。
- **沉浸式右侧详情与动作面板**：
  - 顶部元信息栏：展示来源应用、前台窗口标题、详细时间戳、字符数与行数统计、图片分辨率。
  - 核心操作栏：大号主按钮 `📋 复制到剪贴板 (Enter)`、辅助按钮 `📄 复制纯文本`、`⭐ 置顶`、`💾 另存图片为...`、`🗑 删除`。
  - 现代视口展示：文本模式支持等宽代码字体与字数统计；图片模式支持防透明透气棋盘格底色与自适应高清缩放展示。
- **全键盘流畅交互**：
  - `↑ / ↓`：在卡片历史列表中平滑切换选中项。
  - `Enter`：立即将选中项复制到剪贴板并可自动隐藏窗口。
  - `Delete`：快速删除当前选中记录。
  - `Ctrl + P`：快速切换当前项置顶/取消置顶。
  - `Ctrl + F`：快速定位搜索框。
- **内置现代设置中心**：
  - 点击顶栏右上角 `⚙ 设置` 按钮，直接在主界面呼出卡片式设置面板，支持配置去重、开机自启、全局热键、自动清理保留条数与保留天数、查看缓存大小与打开数据目录。
- **快捷清理**：
  - 点击顶栏右上角 `🗑 清理` 按钮，支持“清空所有非固定记录”（保留常用置顶项）或“清空全部历史”。

### 固定记录

固定记录会优先显示，并且不会被自动清理规则删除。适合保存常用地址、模板、代码片段、图片素材等。

### 自动清理

托盘菜单 `设置` 中可配置：

- 保留条数：不限、最近 100 条、最近 500 条、最近 1000 条。
- 保留天数：不限、最近 7 天、最近 30 天、最近 90 天。

自动清理只删除非固定记录。默认规则为不限条数、不限天数，避免升级或首次运行时误删历史。

### 去重

默认开启去重。同一份内容再次复制时，不会新增重复记录，而是把原记录移动到最新位置并更新来源信息。

### 开机自启

托盘菜单 `设置 -> 开机自动启动` 可开启或关闭开机自启。该设置写入当前用户的 Windows Run 注册表项：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
```

### 全局快捷键

默认快捷键为：

```text
Ctrl + Shift + V
```

如果该快捷键被其他程序占用，剪藏会在托盘提示快捷键不可用。可以在托盘菜单 `设置` 中关闭全局快捷键。

## 操作建议

- 常用文本或图片建议固定，避免被清理规则删除。
- 搜索时可直接输入来源程序名，例如 `chrome`、`word`、`wechat`。
- 图文记录需要只粘贴文字时，使用“纯文本”按钮或列表右键的“复制为纯文本”。
- 长期运行时建议开启去重，历史会更干净。
- 如果经常重启电脑，可以开启开机自启。

## 故障排查

### 双击 EXE 后没有弹出窗口

这是默认行为。剪藏启动后会在后台托盘运行，不主动弹出主窗口。

可以通过以下方式打开历史窗口：

- 右键托盘图标，点击 `查看历史记录`。
- 双击托盘图标。
- 再次双击 `剪藏.exe`，已有后台实例会被唤醒。

如果托盘图标不可见，请检查任务栏右下角的隐藏图标区域。

### `Ctrl + Shift + V` 没有反应

可能原因：

- 快捷键被其他程序占用。
- 剪藏没有运行。
- 托盘设置里关闭了全局快捷键。

处理方式：

- 右键托盘图标，检查 `设置 -> 全局快捷键 Ctrl+Shift+V` 是否已勾选。
- 退出并重新启动剪藏。
- 如果仍然不可用，说明该组合键可能已被其他程序注册。

### 快捷历史菜单无法关闭或触发闪退

请使用最新构建版本。旧版本曾在快捷菜单关闭时过早释放 `ContextMenuStrip`，可能出现“无法访问已释放的对象”错误。

当前版本已改为复用快捷菜单实例，并在弹出菜单前激活应用窗口，点击菜单外区域应能正常关闭。

### 历史记录突然变少

请检查托盘菜单 `设置` 中的自动清理规则。自动清理只删除非固定记录，固定记录不会被自动清理。

### 想彻底清除本地数据

先退出剪藏，然后删除数据目录：

```text
%AppData%\JianCang
```

## 数据与隐私

剪藏只在本机保存数据，不主动上传任何剪贴板内容。

默认数据位置：

```text
%AppData%\JianCang
```

主要文件：

```text
%AppData%\JianCang\history.json
%AppData%\JianCang\settings.json
%AppData%\JianCang\images\*.png
```

注意事项：

- 剪贴板历史可能包含敏感内容，例如密码、验证码、Token、身份证号、银行卡号等。
- 当前版本没有加密本地历史数据。
- 如果需要处理高敏感信息，建议临时退出剪藏，或在使用后清空相关记录。

## 项目结构

```text
.
├─ Assets\
│  └─ 剪藏.ico
├─ dist\                 # 本地构建后生成，发布时建议上传到 GitHub Releases
│  └─ 剪藏.exe

│  └─ Program.cs
```

核心文件说明：

- `src\Program.cs`：WinForms 应用源码，包含剪贴板监听、托盘菜单、历史窗口、设置、热键和单实例逻辑。
- `build.ps1`：生成图标并编译 EXE。
- `Assets\剪藏.ico`：应用图标。
- `dist\剪藏.exe`：本地构建后的可执行文件；正式分发时建议作为 GitHub Release 附件上传。

## 开发说明

当前实现为单文件 WinForms 应用，目标是降低构建和分发门槛。主要技术点：

- `AddClipboardFormatListener` 监听剪贴板更新。
- `NotifyIcon` 提供托盘常驻和右键菜单。
- `RegisterHotKey` 注册全局快捷键。
- `Mutex` 保证单实例运行。
- `DataContractJsonSerializer` 持久化历史和设置。
- 图片记录以 PNG 文件保存。

## 已知限制

- 只记录程序运行期间产生的剪贴板内容。
- 图片 OCR、富文本格式保留、应用黑名单和历史加密暂未实现。
- 来源程序依赖当前前台窗口信息，某些场景下可能显示为未知或不准确。
- 全局快捷键可能被其他应用占用。

## 路线图

后续可考虑：

- 本地数据加密。

- 导入 / 导出历史记录。
- 更完整的设置窗口。
- 安装包、自动更新和签名发布。
